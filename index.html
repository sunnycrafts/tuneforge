        🚀 Quick start

        • Drop songs or a whole folder onto the Convert tab.
        • Pick a preset on the right. For iTunes, iTunes AAC 256 is the same quality the iTunes Store sells; Apple Lossless if you want a perfect copy.
        • Choose where the files go and how they're named, then press Convert All.
        • Tick Check tags in the Tag Fixer when done to have missing artist, album and cover info looked up afterwards.

        Hover over any i for an explanation of that setting.

        🎛️ What the quality slider really does

        Every lossy format reads the same 0–100 slider and turns it into its own setting. The box under the slider always shows the exact result. Some reference points:

        SliderMP3 (VBR)AACOpusWhat it sounds like
        100V0 ≈ 245 kbps320 kbps256 kbpsBest the format can do. Larger than you need.
        85V1 ≈ 225 kbps256 kbps192 kbpsTransparent: same as the source to nearly everyone.
        60V4 ≈ 165 kbps192 kbps128 kbpsVery good. Great for phones.
        30V6 ≈ 115 kbps128 kbps64 kbpsOK for music on small speakers; good for voice.
        0V9 ≈ 65 kbps64 kbps32 kbpsSpeech only.

        Quality only goes down, never up. If the original is a 128 kbps MP3, setting 100 makes a bigger file that still sounds like 128 kbps. The queue warns you when that happens. For lossless formats the slider does nothing, since nothing is thrown away.

        🏷️ Tags, album art and iTunes

        TuneForge copies all tags and the embedded cover from the original into the converted file, including between formats that store them differently (for example Opus/Ogg tags into an M4A or MP3). Each finished file is read back to check the cover made it.

        MP3s are written with ID3v2.3 tags, the version iTunes and Windows Explorer read most reliably. M4A files use the same tag layout as iTunes Store purchases.

        Add to iTunes copies finished files into iTunes' “Automatically Add to iTunes” folder. iTunes then imports them into your library within a few seconds, sorted by artist and album with their artwork.

        🔎 How the Tag Fixer works

        • It reads the file's tags. If they're missing or junk ("Unknown Artist", "Track 01", website names), it works out the artist and title from the filename, removing things like (Official Video), [Lyrics], 320kbps, track numbers and YouTube IDs.
        • It searches iTunes and Deezer (both free, no account) and scores each match by title, artist and song length, so live versions, karaoke and cover versions rank lower.
        • It shows what it found and how sure it is. Nothing is written until you press Accept. You can edit any field, pick another match or type your own search.
        • For artwork you get the album covers from the matches (up to 1200×1200) plus an artist photo for songs with no album.
        • Optional: audio fingerprinting (Settings) recognises the song from its sound, like Shazam, for files with no useful name at all. It needs a free AcoustID key.
        • You can also rename files from their new tags, or sort them into Artist\Album\01 Title folders.

        💡 Tips

        • Keep a lossless master (FLAC or Apple Lossless) and make lossy copies from it. Converting MP3 → AAC → MP3 loses quality every time.
        • If you only listen in iTunes, turn on iTunes' own Sound Check instead of “Even out loudness”; it adjusts playback without changing the files.
        • Dropping a video file (MP4, MKV, MOV…) pulls its soundtrack out as audio.
        • Everything TuneForge does is listed in History, including the exact error when a file fails.
